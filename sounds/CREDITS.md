# Sound credits

Recorded samples that replace the game's synthesized sounds. Name a file after the bank sound it replaces
(see `BANK` in `src/game.ts`), e.g. `pistol-1.ogg`, `pistol-2.ogg`, then run `python3 tools/sound_manifest.py`.
